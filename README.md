# Kintsugi Washing Machine Diagnostic App (Frontend)

A modern Flutter mobile application designed to assist Samsung washing machine technicians with AI-powered diagnosis and support capabilities.

## Features
- Animated splash screen with Kintsugi logo (Samsung blue/navy blue)
- Onboarding with 3-4 feature slides (using provided asset images)
- Login page (demo credentials only)
- Chat-like interface for text queries
- Icons for audio analysis, image diagnosis, and voice integration
- Modern, clean UI using provided assets

## Getting Started
1. Ensure you have Flutter installed.
2. Run `flutter pub get` to fetch dependencies.
3. Run `flutter run` to launch the app.

## Asset Images
Place your images in `assets/app-images/` as referenced in onboarding and splash screens.
